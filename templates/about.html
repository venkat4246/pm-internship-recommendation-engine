PROJECT OVERVIEW

AI-Based Internship Recommendation Engine for PM Internship Scheme

A student-facing prototype that helps users discover relevant internship opportunities by comparing their profile with internship requirements.

Frontend

HTML, CSS and JavaScript provide the responsive user interface and profile form.

Backend

Python Flask receives profile details, reads internship records and returns ranked matches.

Database

SQLite stores sample internship information. It can be migrated to MySQL for a larger deployment.

AI / ML

Scikit-learn TF-IDF and cosine similarity provide a simple content-based recommendation method.

Important limitation

This is an academic prototype, not an official government website. The sample internships are fictional examples for testing. Do not present them as current vacancies or official scheme listings.
